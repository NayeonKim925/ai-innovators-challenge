# Continuum · 컨티뉴엄

> 근무는 끝나도, 조사는 끊기면 안 됩니다.

Continuum은 미완료 제조 이상 조사가 담당자 교대 때문에 다시 시작되지 않도록, 같은 Case의 분석 Run·근거·관찰·미확인 항목·사람의 판단을 이어 주는 워크스페이스입니다.

## 이름과 표기

**Continuum**은 조사 상태가 교대 전후에도 끊기지 않고 이어진다는 의미입니다. 한글 표기는 **컨티뉴엄**, 영문은 **Continuum**으로 통일합니다. API 경로, 저장 ID, AWS 리소스명, 데이터셋 이름은 운영 호환성을 위해 바꾸지 않습니다.

## 제품 약속

- 다음 담당자는 같은 Case에서 현재 분석 Run, 근거, Open Item, 인계 Snapshot과 변경 이력을 확인하고 조사를 재개합니다.
- 후보 순위는 결정론적 분석 도구의 조사 우선순위이며 원인 확률·확정 원인이 아닙니다.
- 인수 수락은 전달 상태를 확인했다는 뜻일 뿐 조사 종료·수리 완료·안전한 재가동을 뜻하지 않습니다.
- LLM은 근거와 현재 상태를 정리할 수 있지만 후보 순위·점수·권위 상태를 바꾸지 않습니다.

**발표용 한 문장:** “Continuum은 어떤 근거가 확인됐고 무엇이 아직 미확인인지 추적해, 교대가 바뀌어도 같은 Case에서 조사를 이어가게 합니다.”

## 시각 자산과 범위

기존 열린 프레임·연결 신호 심볼은 조사 근거의 연결을 나타내는 비권위적 시각 자산으로 유지합니다. 실제 텍스트 워드마크만 Continuum으로 바꾸며, 로고 자체가 확정·인증을 뜻하지 않습니다. 색상·Pretendard·접근성 규칙은 [DESIGN.md](../DESIGN.md), 자산 출처는 [BRAND_ASSETS.md](BRAND_ASSETS.md)를 따릅니다.

현재 서비스는 공개 데이터 기반 연구용 MVP입니다. 실제 공장 운영, 사용자별 인증·조직 권한, 실시간 공동 편집, 자동 설비 제어는 제공하지 않습니다. 상표·도메인 사용 가능성은 상용 출시 전에 별도로 검토해야 합니다.
