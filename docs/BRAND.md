# Cluephase · 클루페이즈

> 신호를 근거로, 근거를 판단으로.

제조 이상을 근거로 조사하고 전문가의 판단을 기록하는 워크스페이스.

## 이름을 선택한 이유

**Clue(단서) + Phase(단계·공정)**. 관측 신호를 단서로 삼아 후보를 좁히고, 사람이 검토하며 다음 조사 단계로 나아가는 제품의 흐름을 담았다. 한글 표기는 **클루페이즈**, 영문은 **Cluephase**로 통일한다. `CluePhase`, `Clue Phase`, `CausePilot`을 새 제품명으로 혼용하지 않는다.

`Cause` 대신 `Clue`를 택한 이유는 제품이 확정된 원인을 보장하지 않기 때문이다. `Factory`나 데이터셋 이름을 넣지 않아 후속 데이터 어댑터도 같은 브랜드 아래 둘 수 있다. 그렇다고 현재 범용 데이터 업로드를 지원한다고 소개해서는 안 된다.

## 누구에게 어떤 가치를 약속하는가

- 공정·설비 전문가: 후보의 근거와 한계를 확인하고 검토 의견을 남긴다.
- 데이터 분석가: 관측값, 진단 시점, 분석 방식과 실행 이력을 함께 확인한다.
- 사건을 넘겨받은 동료: 이전 조사 결과와 검토 맥락을 보고 다음 확인 대상을 찾는다.

**발표용 한 문장:** “Cluephase는 공정 이상이 발생했을 때 관측 신호와 원인 후보, 분석 근거와 전문가 검토를 한 흐름으로 연결하는 AI 보조 조사 워크스페이스입니다.”

현재 제공하는 것은 공개 HIL 데이터 기반 공유 검증 환경이다. 실제 공장 운영, 조직별 권한, 실시간 공동 편집, 자동 설비 제어는 제공하지 않는다. LLM 해설은 선택 기능이고 수치 계산과 후보 순위는 분석 도구가 담당한다.

## 언어와 표현

| 위치 | 표현 |
| --- | --- |
| 주 슬로건 | 신호를 근거로, 근거를 판단으로. |
| 보조 문구 | 근거를 먼저, 판단은 함께. |
| 제품 설명 | 제조 이상 조사 워크스페이스 |
| 영문 설명 | Evidence workspace |
| AI의 역할 | 조사 후보와 근거를 정리합니다. |
| 전문가의 역할 | 근거와 한계를 검토하고 판단을 기록합니다. |

화면의 버튼은 `조사 실행`, `전문가 검토`, `보고서`처럼 수행할 일을 직접 쓴다. `진짜 원인 발견`, `정확도 99%`, `AI가 해결 완료`, `공장을 자율 운영` 같은 검증되지 않은 표현은 쓰지 않는다. 미확인 후보는 후보로, 자료가 없으면 근거 부족으로 표시한다.

## 시각 정체성

기존 imagegen 심볼을 유지한다. 열린 각진 프레임은 조사 범위, 연결선과 노드는 관측 단서의 연결을 표현한다. 확정·인증을 뜻하는 체크마크로 사용하지 않는다. 로고 안에 생성형 텍스트를 넣지 않고 실제 글꼴로 이름을 표시해 작은 화면에서도 선명하게 만든다.

- Deep navy `#142D35`: 작업 공간의 바탕, 침착함.
- Signal teal `#167D7B`: 조사 실행과 선택 강조.
- Ink `#18333B`, canvas `#F5F7F8`: 장시간 근거를 읽는 화면.
- Amber `#946019`: 주의·제약. 브랜드 장식 색으로 남용하지 않는다.
- 글꼴: 로컬 Pretendard Variable와 시스템 고정폭 글꼴. 제목은 450 중심, 본문 400–500으로 무게를 낮추고 사건 ID와 숫자는 고정폭으로 구분한다. 이름보다 조사 내용이 먼저 읽히도록 한다. 새 폰트 의존성은 추가하지 않는다.
- 심볼과 워드마크 간격 9px, 로고 주변 최소 8px 여백. 심볼 최소 24px, 화면 워드마크 최소 14px. 로고를 늘이거나 그라디언트·그림자로 변형하지 않는다.
- 문서·발표에서는 첫 등장에 `Cluephase(클루페이즈)`와 제품 설명을 함께 쓴다. 출처/근거와 브랜드가 경쟁하지 않도록 본문에서는 이름을 반복하지 않는다.

시각 견본은 [브랜드 보드](brand-board.html), 자산 출처는 [BRAND_ASSETS.md](BRAND_ASSETS.md), 전체 UI 규칙은 [DESIGN.md](../DESIGN.md)를 따른다.

## 후보 비교와 조사 한계

2026-09-17 간단한 공개 웹 검색에서 `Cluephase`, `클루페이즈`와 직접 일치하는 제품을 확인하지 못했다. 검색 누락 가능성이 있으며 **상표 등록 가능성, 도메인 가용성, 법적 사용 권리 확인이 아니다**. 상용 출시 전 별도 검토한다. 도메인을 구매하거나 기존 AWS 리소스명을 바꾸지 않았다.

- Clueframe: 의미는 좋지만 [동명 조사형 교육 제품](https://clueframe.com/?lang=de)이 있어 제외.
- Causcope: [동명 가설·문헌 검증 서비스](https://www.causal-atlas.app/)가 있고 원인 확정의 인상이 강해 제외.
- Cluephase: 공정과 조사 단계를 함께 설명하고, 단서와 최종 판단을 구분하는 현재 제품과 가장 잘 맞아 선택.

Lazyweb 검색에서 Rows·Dovetail·Tango의 워크스페이스/브랜딩 화면 메타데이터를 확인했다. 브랜드를 내비게이션에 고정하고, 실제 작업 공간 이름과 구분하는 원칙만 참고한다. 로고나 타사의 고유 시각 자산을 제품에 복제하지 않는다.

## 이번 적용 범위 / 검증 기준

브랜드 상수, 사이드바, 브라우저 제목·메타데이터, 사용 안내, 푸터, 보고서 파일명·표지, README에 적용한다. 분석 알고리즘·API·원본 데이터·저장 ID·AWS 리소스명은 바꾸지 않는다. 기존 브라우저 조사 기록 키도 유지한다.

브라우저 테스트에서 이름·제목·메타데이터와 보고서 내용, 390px·1440px 레이아웃을 확인한다. 기존 조사→근거→검토→질문→보고서 흐름이 유지되어야 한다.
