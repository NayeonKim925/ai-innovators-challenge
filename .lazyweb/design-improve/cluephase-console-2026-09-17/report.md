# Cluephase: 카드 대시보드에서 조사 기록부로

## 요청과 유지할 것
네이비·청록, 브랜드, 실제 조사 흐름은 유지한다. 균일한 굵은 글자, 둥근 카드 중첩, 의미 없는 아이콘 반복을 줄인다. 분석 계산·API 계약·근거 한계는 변경하지 않는다.

## 확인한 레퍼런스
- Inspo `minimal-so--changelog` — https://minimal.so : 날짜/내용을 정렬한 평면 문서 위계. 굵은 영문 제목 자체는 복사하지 않는다.
- Inspo `glyphsapp-com--learn` — https://glyphsapp.com/learn : 순서 있는 항목과 수평 구분선. 거대한 세리프와 주황 카드 레이아웃은 제외한다.
- Inspo `motherduck-com` — https://motherduck.com : 기술 메타정보를 구분하는 monospace와 사각 컨트롤. 홍보 일러스트·팝업·색상은 제외한다.
- Lazyweb Databricks catalog: 내려받아 확인한 `references/databricks.png`. 연결된 탐색 패널과 표 중심 작업 공간을 참고한다.
- Lazyweb Mixpanel: `references/mixpanel.png`. 목록 정렬만 참고하며 환영 배너·추천 카드는 제외한다.

Inspo 세 화면은 문서·마케팅 화면이다. 실제 제조 제품의 사용성 근거라고 주장하지 않는다. 캡처의 구성 원리를 현재 조사 업무에 맞게 변형한다. 타사 이미지·폰트·로고를 제품 자산으로 복제하지 않는다.

## 변경 계획
1. 상단 세 개 지표 카드를 `dl` 형태의 얇은 조사 환경 요약으로 교체한다. 수치 과장과 장식 아이콘을 없앤다.
2. 사건 목록과 상세를 연속된 두 열로 붙인다. 선택 사건만 청록 레일로 표시한다. 매 행의 같은 준비 뱃지를 삭제한다.
3. 제목은 24px와 가벼운 두께로, 설명·표는 읽기 쉬운 크기로 조정한다. 기존 로컬 폰트를 유지하되 ID와 기술 메타정보에 고정폭 글꼴을 분리한다.
4. 패널·버튼의 라운드와 그림자를 줄이고 정보 위계를 여백·구분선·정렬로 표현한다.

## 회귀 검증
기존 E2E가 조사 실행, abstention, 관측 알람 시점 이동, 근거, 검토 저장, 질문, 보고서, 기록 복원, 모바일, 오류 복구를 고정한다. 변경 후 build/typecheck, Node 테스트, 실제 로컬 API E2E, 1440/390px 스크린샷을 확인한다. 원본 데이터나 평가 정답을 UI 수정에 사용하지 않는다.

## 시각 검토 기준
카드 중첩 제거, 제목 무게 감소, 좁은 화면 넘침 없음, 핵심 버튼·안전 문구 유지. 시각 점수는 자체 판단이며 사용자 만족도나 외부 평가가 아니다.

## 구현·검증 결과
- `frontend/src/App.tsx`: 의미론적 요약 목록, 반복 준비 뱃지·아이콘 삭제. 상태·이벤트 핸들러는 보존했다.
- `frontend/src/styles.css`: 연결된 패널, 행 단위 사건, 선택 레일, 가벼운 제목, 고정폭 ID. 후보와 근거도 같은 평면 언어로 정리했다.
- 320px 메뉴 넘침, 390px 요약 줄바꿈 및 브랜드 숨김을 시각 검수에서 발견해 수정했다. 메뉴 이름은 숨기지 않고 줄바꿈한다.
- typecheck/build, Node 10개, Playwright 4개 통과. 테스트는 로컬 실제 API와 연결했으며 LLM 성능은 측정하지 않았다.
- 최종 스크린샷: `docs/ui/desktop-workspace.png`, `docs/ui/desktop-results.png`, `docs/ui/mobile-workspace.png`.
- 자체 시각 검토 68 → 84 → 87 → 91. 독립 사용자 평가 점수는 아니다. 세부 기록은 로컬 `.omx/state/cluephase-console/ralph-progress.json`.
- 남은 작은 정리: 모바일 사건 목록의 우측 테두리 표현과 일부 미사용 CSS 선택자는 후속 정리가 가능하다. 기능 회귀는 발견되지 않았다.
