# Cluephase 브랜드 레퍼런스 보완

제품 이름은 내비게이션에 고정하고, 실제 작업 공간과 데이터 범위는 별도로 설명한다.

## 근거와 적용

- **[Web, 기존 시각 레퍼런스]** [Metabase 공식 Drill-through](https://www.metabase.com/features/drill-through): 요약에서 근거로 진입하는 작업 위계를 유지한다. [기존 캡처](../investigation-2026-09-17/references/metabase.png).
- **[Lazyweb, 메타데이터만 확인]** `analytics workspace sidebar branding`, desktop, limit 3 검색 성공. Rows 251668, Dovetail 251474, Tango 250439의 워크스페이스·브랜딩 설정 화면 설명을 확인했다. 해당 이미지 자체는 직접 검토하지 않았다. 제품 브랜드와 작업 공간 이름의 구분만 보조 근거로 활용한다.
- **[자체 구현]** Cluephase 워드마크 아래 `클루페이즈 · 근거 중심 조사`, 작업 공간에는 `제조 이상 조사 / 공개 데이터 · 공유 검증 공간`을 표시한다.

```text
심볼 + Cluephase            제품 정체성
제조 이상 조사             현재 작업 공간
공개 데이터 · 공유 검증 공간 실제 이용 범위
사건 조사 / 조사 기록 / 데이터셋
```

원격 도구의 설치 업데이트 요청은 사용자 제품 브랜딩 범위 밖이므로 실행하지 않았다. 추가 설정 기능이나 타사 브랜드 자산을 구현에 가져오지 않았다.
