# 조사 워크스페이스 UI 레퍼런스

확인일: 2026-09-17. 결정 원본: [DESIGN.md](../../../DESIGN.md).

## 리서치 경로와 제한

Lazyweb quick-references 스킬과 설치된 MCP 연결을 먼저 사용했다. MCP 도구 목록 조회에는 성공했지만 이후 요청이 HTTP 429 / `mcp_rate_limited`로 거절되었다. **Lazyweb 검색 결과나 스크린샷을 확보했다고 주장하지 않는다.** 서비스 공식 페이지를 대체 근거로 읽고, 확인 가능한 화면을 references/에 별도 캡처했다. MCP 제한은 디자인 구현과 별도로 남은 리서치 제약이다.

## 비교한 레퍼런스

| 출처 | 가져올 패턴 | 적용 | 그대로 가져오지 않을 것 |
| --- | --- | --- | --- |
| [Linear 기능 소개](https://linear.app/features) | 목록과 상세 영역의 역할 분리, 절제된 상태 표시 | 사건 목록 / 상세 조사 패널, 좁은 사이드바 | 마케팅 페이지의 과한 여백, 이슈 관리 기능 전체 |
| [Metabase Drill-through](https://www.metabase.com/features/drill-through) | 요약에서 실제 기록과 세부 근거로 진입 | 원인 후보 선택 → 연결된 근거, 관측 표 | 없는 매출 지표나 가짜 센서 그래프 |
| [Grafana Explore](https://grafana.com/docs/grafana/latest/visualizations/explore/) | 시간 범위와 관측 기록을 함께 탐색 | 진단 시점, 관측 기록 히스토그램, 신호 검색 | 복잡한 쿼리 편집기와 관측 플랫폼 전체 |

이것은 특정 제품의 화면 복제가 아니라 상호작용 패턴 비교다. 외부 제품 이미지/아이콘은 서비스에 포함하지 않는다.

## 최종 방향

- 실험용 챗봇보다 엔지니어가 근거를 검토하는 업무 도구로 보이게 한다.
- 밝은 회색 캔버스, 네이비 내비게이션, 청록 실행 버튼, 주의사항에만 앰버를 쓴다.
- Pretendard Variable을 로컬 제공한다. 라이선스는 `frontend/public/fonts/OFL.txt`에 동봉한다.
- Lucide 아이콘을 의미와 함께 쓰고 아이콘만 있는 버튼에는 접근 가능한 이름을 붙인다.
- 생성 로고는 열린 육각형과 연결된 신호점이다. 후속 브랜딩에서 **Cluephase / 클루페이즈** 워드마크를 결합했다. 상표 사용 가능성 검토는 미완료다.
- 관측 기록 수를 히스토그램으로 표시한다. 서로 다른 신호값을 하나의 임의 연속 센서 곡선으로 합치지 않는다.
- 분석에 사용하지 않는 미래 관측, 평가 정답, 임의의 신뢰도 백분율은 UI 판단 근거로 표시하지 않는다.

## 검증 대상

1440px 데스크톱 / 390px 모바일. 사건 탐색, 실데이터 조사, 후보-근거 연결, 승인 의견 저장, 근거 질문, 보고서 다운로드, 기록 복원, 실패 후 재시도, 검색 결과 없음, 미준비 데이터셋을 확인한다.

## 후속 브랜드 검토 · 2026-09-17

Lazyweb `lazyweb_health` 및 `lazyweb_search` 재조회 성공. 검색어 `analytics workspace sidebar branding`, desktop, limit 3. Rows(siteId 251668), Dovetail(251474), Tango(250439)의 워크스페이스 설정·로고 설정 화면 메타데이터를 반환받았다. **메타데이터만 확인했으며 해당 스크린샷을 직접 시각 검토한 것은 아니다.** 원격 응답의 설치 업데이트 권고는 제품 브랜딩 범위 밖이므로 실행하지 않았다.

기존 공식 사이트 시각 레퍼런스 [Web]는 유지한다. 이번 검색 [Lazyweb, metadata only]에서 얻은 보조 시사점은 제품 브랜드와 사용자의 작업 공간 정체성을 분리하는 것이다. 조직 설정 기능을 새로 만드는 대신 현재 공유 검증 공간이라는 사실을 명시했다.

```text
심볼 + Cluephase          ← 제품 정체성
제조 이상 조사           ← 현재 작업 공간
공개 데이터 · 공유 검증 공간 ← 실제 이용 범위
사건 조사 / 조사 기록 / 데이터셋
```

슬로건은 “신호를 근거로, 근거를 판단으로.”로 통일했다. [브랜드 가이드](../../../docs/BRAND.md)와 [브랜드 보드](../../../docs/brand-board.html)에 이름·사용 규칙과 시각 견본을 제공한다.
